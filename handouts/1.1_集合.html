1.1 集合（五年高考三年模拟·A版）

一、 核心概念速记

考点 1：集合及其关系

1. 集合的含义与表示

  • 元素的三特性：确定性、互异性、无序性。
  • 元素与集合的关系：属于（用符号 ∈ 表示）或不属于（用符号 ∉ 表示）。
  • 常用数集及符号：
  • 非负整数集（自然数集）ℕ
  • 正整数集 ℕ\* （或 ℕ₊）
  • 整数集 ℤ
  • 有理数集 ℚ
  • 实数集 ℝ
  • 集合的表示方法：列举法、描述法、图示法（Venn 图）。

    • 2. 集合间的基本关系

    关系文字语言记法
    相等集合 A 的任何一个元素都是集合 B 的元素，同时集合 B 的任何一个元素都是集合 A 的元素A = B
    子集集合 A 中任意一个元素均为集合 B 中的元素A ⊆ B 或 B ⊇ A
    真子集如果集合 A ⊆ B，但存在元素 x ∈ B，且 x ∉ A，则称 A 是 B 的真子集A ⊊ B 或 B ⊋ A

    💡 有限集的子集个数：设集合 A 是有 n 个元素的有限集，即 card(A) = n（n ∈ ℕ\*），则：

    - 子集个数为 2ⁿ

    - 真子集个数为 2ⁿ - 1

    - 非空子集个数为 2ⁿ - 1

    - 非空真子集个数为 2ⁿ - 2

    🔭 知识拓展

    1. 德·摩根定律：

    $$C_{U}(A \cup B) = (C_{U}A) \cap (C_{U}B)$$

    $$C_{U}(A \cap B) = (C_{U}A) \cup (C_{U}B)$$

    2. 容斥原理：对任意两个有限集合 A，B，有：

    $$\text{card}(A \cup B) = \text{card}(A) + \text{card}(B) - \text{card}(A \cap B)$$

    二、 核心题型与母题

    题型一：集合间基本关系的求解及应用

    判断三法：

    方法适用场景
    列举法元素个数少时，列出全部元素逐一判断
    元素特征法确定集合的代表元素，弄清其特征后判断
    数形结合法利用数轴或 Venn 图，适合不等式的解集间关系的判断

    【典例 1】（2021·全国乙理，2·5分）已知集合 S = { s | s = 2n+1, n ∈ ℤ }，T = { t | t = 4n+1, n ∈ ℤ }，则 S ∩ T = （　　）

    A. ∅　　B. S　　C. T　　D. ℤ

    【思路点拨】：S 是全体奇数的集合，T 是被 4 除余 1 的整数集合。T 中的元素形如 …,-3,1,5,9,…，全部是奇数，故 T ⊆ S，即 S ∩ T = T。

    【规范解答】：答案选 C。

    $$S = \{\ldots, -3, -1, 1, 3, 5, \ldots\} \text{（全体奇数）}$$

    $$T = \{\ldots, -7, -3, 1, 5, 9, \ldots\} \text{（被4除余1的整数）}$$

    T 中任意元素 t = 4n+1 = 2(2n)+1，必为奇数，故 T ⊆ S，从而 S ∩ T = T。

    题型二：集合运算问题的求解

    常用三方法：

    方法适用场景
    先"简"后"算"根据元素特性区分数集或点集，先化简再运算
    遵"规"守"矩"交集抓"公共元素"；并集"合并"；补集关注"你有我无"
    借"形"助"数"借助 Venn 图或数轴使抽象问题直观化，端点取舍要留意

    【典例 3】（2024·浙江三模，2分）已知集合 A = { x | log₃(x+2) > 1 }，B = { x | x(x-2) < 0 }，则 A ∩ (∁ᴿB) 等于（　　）

    A. ∅　　B. (0,1)　　C. (1,2)　　D. [2,+∞)

    【思路点拨】：先分别求 A、B 的解集，再求 B 关于 ℝ 的补集，最后取交集。

    【规范解答】：答案选 D。

    $$A: \log_3(x+2) > 1 \Rightarrow x+2 > 3 \Rightarrow x > 1, \quad A = (1, +\infty)$$

    $$B: x(x-2) < 0 \Rightarrow 0 < x < 2, \quad B = (0, 2)$$

    $$C_{\mathbb{R}}B = (-\infty, 0] \cup [2, +\infty)$$

    $$A \cap C_{\mathbb{R}}B = (1,+\infty) \cap \left((-\infty,0] \cup [2,+\infty)\right) = [2, +\infty)$$

    【典例 4】 已知集合 A = { x | (x-2)(x-3) ≥ 0 }，B = { x | x > a-1 }，若 A ∪ B = ℝ，则实数 a 的取值范围是（　　）

    A. (3,+∞)　　B. [2,+∞)　　C. (-∞,2]　　D. (-∞,3]

    【思路点拨】：先求 A 的解集，由 A ∪ B = ℝ 推导 B 必须覆盖 (2,3) 这段"缺口"，进而反推 a 的范围。

    【规范解答】：答案选 D。

    $$A = (-\infty, 2] \cup [3, +\infty)$$

    A 的补集为开区间 (2,3)，要使 A ∪ B = ℝ，B 必须覆盖 (2,3) 中所有点，即：

    $$a - 1 \leq 2 \Rightarrow a \leq 3$$

    故 a 的取值范围为 (-∞, 3]。

    三、 易错坑点防雷

  • 🧨 易错点 1（空集必须讨论）：解决集合间关系 A ⊆ B 或 A ⊊ B 的问题时，若集合 A 中含有参数，通常要分 A = ∅ 和 A ≠ ∅ 两种情况讨论。A = ∅ 的情况极易被忽略，必须引起重视！
  • 🧨 易错点 2（点集与数集混淆）：集合 { y | y = 2x, x ∈ ℝ } 与集合 { (x,y) | y = 2x, x ∈ ℝ } 不同！前者是数集（值域），后者是点集（直线上的点）。
  • 🧨 易错点 3（子集遗忘空集）：∅ 是任何集合的子集；∅ 是任何非空集合的真子集。求子集时绝不能遗漏 ∅！
  • 🧨 易错点 4（互异性验证）：求参数值后，必须将结果代回集合验证元素满足互异性，不能出现重复元素。
  • 🧨 易错点 5（补集端点取舍）：利用数轴求补集时，原集合的开/闭端点对应补集的闭/开端点，务必仔细判断 < 与 ≤ 的边界。
