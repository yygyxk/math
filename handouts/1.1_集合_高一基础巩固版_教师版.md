## 一、 趣味引入与知识精讲

### 🎯 课堂引入：物以类聚，人以群分
**【教师引导话术】**：
大家想象一下，如果现在学校要组织一场篮球赛，要求“身高1米8以上的男生”出列组队，这群男生就构成了一个**“集合”**。但是，如果老师说“请班里‘长得比较帅’的男生出列”，大家觉得这能构成一个集合吗？显然不能，因为每个人对“帅”的标准不一样。
这就是我们要学的第一个核心概念——**确定性**。数学里的集合，标准必须是死的，不能含糊！

### 考点 1：集合的含义与表示

**1. 集合中元素的三大特性**
- **确定性**：标准明确。比如“接近 $0$ 的实数”不能构成集合，“大于 $0$ 的实数”可以。
- **互异性**：集合里不能有长得一样的双胞胎。
  - 🎤 **【师生互动提问】**：如果我写出一个集合 $A = \{1, 1, 2\}$，大家觉得对吗？
  - *【教师预设回答】*：不对！如果求出来参数导致集合里出现了两个 $1$，必须要划掉这个解！这就是考试中最爱挖坑的地方！
- **无序性**：顺序无所谓。$\{1, 2, 3\}$ 和 $\{3, 2, 1\}$ 是同一个集合。

**2. 常用数集及符号（死记硬背区）**
- $\mathbb{N}$：自然数集（一定要记住它**包含** $0$！）
- $\mathbb{N}^*$ 或 $\mathbb{N}_+$：正整数集（不含 $0$）
- $\mathbb{Z}$：整数集
- $\mathbb{R}$：实数集

**3. 集合间的基本关系（谁包含谁）**

| 关系 | 文字语言 | 记法 |
|:---:|:---|:---:|
| **相等** | 集合 $A$ 与集合 $B$ 的元素完全一样 | $A = B$ |
| **子集** | 集合 $A$ 中任意一个元素都在集合 $B$ 中（$A$ 小 $B$ 大） | $A \subseteq B$ |
| **真子集** | $A$ 是 $B$ 的子集，且 $B$ 中至少有一个元素不在 $A$ 中 | $A \subsetneq B$ |

> 💡 **子集个数口诀**：
> 一个集合如果有 $n$ 个元素：
> - 它的子集有 $2^n$ 个。
> - 真子集有 $2^n - 1$ 个（排除了自己）。
> - 非空真子集有 $2^n - 2$ 个（排除了自己和空集）。
> 🎤 **【师生互动提问】**：空集 $\varnothing$ 有几个子集？（答：1个，就是它自己，$2^0=1$）。

## 二、 必背符号与性质

| 运算 | **并集** | **交集** | **补集** |
|:---:|:---:|:---:|:---:|
| **符号语言** | $A \cup B = \{ x \mid x \in A \text{ 或 } x \in B \}$ | $A \cap B = \{ x \mid x \in A \text{，且 } x \in B \}$ | $\complement_{U}{A} = \{ x \mid x \in U \text{，且 } x \notin A \}$ |
| **形象记忆** | ∪ 像个大碗，把两边全部装进来 | ∩ 像个帽子，只能盖住两人都有的部分 | $U$ 是整个宇宙，$\complement_{U}{A}$ 就是宇宙里除了 $A$ 的剩下部分 |
| **核心性质** | $A \cup A = A$ <br> $A \cup B = B \Leftrightarrow A \subseteq B$ | $A \cap A = A$ <br> $A \cap B = A \Leftrightarrow A \subseteq B$ | $A \cup (\complement_{U}{A}) = U$ <br> $A \cap (\complement_{U}{A}) = \varnothing$ |

**🔭 教师点拨：解题两大终极武器**
- **离散的数字**：直接“找相同”或“全合并”。
- **连续的区间（带有 $<$ 或 $\leq$）**：**必须画数轴**！实心点代表包含，空心圈代表不包含。

## 三、 核心考向与阶梯训练（大体量）

### 题型一：集合元素的互异性与概念辨析

**【考查知识点】**：互异性检验、一元二次方程
**【典例 1】** 已知集合 $A = \{1, x, x^2-x\}$，若 $0 \in A$，求实数 $x$ 的值。

**【思路点拨】**：既然 $0$ 在集合里，那 $x$ 和 $x^2-x$ 必有一个是 $0$。解出来之后一定要“验算”，看看集合里会不会出现两个 $0$ 或两个 $1$！

**【规范解答】**：
分两种情况讨论：
① 若 $x = 0$，此时 $x^2-x = 0$，集合变成 $A = \{1, 0, 0\}$。
由于违背了元素的互异性，舍去！
② 若 $x^2-x = 0$，解得 $x = 0$ 或 $x = 1$。
当 $x = 0$ 时，同上，舍去；
当 $x = 1$ 时，集合变成 $A = \{1, 1, 0\}$，同样违背互异性，舍去。
综上，不存在满足条件的实数 $x$。

**【考查知识点】**：集合的确定性判断
**【变式 1-1（基础巩固）】**
下列各组对象能构成集合的是（　　）
A. 高一（1）班视力比较差的同学
B. 所有的正偶数
C. 某中学内长得高的树
D. 接近于 $0$ 的实数
**【规范解答】**：选 B。A中的“视力比较差”、C中的“高”、D中的“接近于0”都没有明确的标准，违背了确定性。

**【考查知识点】**：点集与数集的辨析
**【变式 1-2（易错挖坑）】**
判断集合 $M = \{y \mid y = x^2\}$ 与集合 $N = \{x \mid y = x^2\}$，以及集合 $P = \{(x, y) \mid y = x^2\}$ 是否相等？
**【规范解答】**：
都不相等！
集合 $M$ 代表元素是 $y$，表示函数值域，所以 $M = [0, +\infty)$。
集合 $N$ 代表元素是 $x$，表示函数定义域，所以 $N = \mathbb{R}$。
集合 $P$ 代表元素是坐标 $(x,y)$，表示抛物线上的点集。
三者完全不同。

### 题型二：连续区间的交并补运算（画数轴）

**【考查知识点】**：数轴法求交、并、补集
**【典例 2】** 已知全集 $U = \mathbb{R}$，集合 $A = \{x \mid -1 \leq x < 3\}$，集合 $B = \{x \mid 2 < x \leq 5\}$。求 $A \cap B$ 和 $\complement_{U}{A}$。

**【思路点拨】**：在草稿纸上画一条数轴，把 $-1, 2, 3, 5$ 四个点标出来，$\leq$ 画实心， $<$ 画空心圈。

**【规范解答】**：
(1) 求 $A \cap B$：在数轴上找两条线重叠的部分，显然是 $2$ 到 $3$ 之间。因为 $B$ 在 $2$ 处是空心（不包含），$A$ 在 $3$ 处也是空心（不包含），所以 $A \cap B = \{x \mid 2 < x < 3\}$。
(2) 求 $\complement_{U}{A}$：找 $U$ 中不属于 $A$ 的部分，注意端点反转！$A$ 中包含 $-1$（实心），补集就不包含（变成空心 $<$）；$A$ 中不包含 $3$（空心），补集就包含（变成实心 $\geq$）。
因此 $\complement_{U}{A} = \{x \mid x < -1 \text{ 或 } x \geq 3\}$。

**【考查知识点】**：一元二次不等式解法与集合运算的结合
**【变式 2-1（基础巩固）】**
设集合 $M = \{x \mid x^2-x-6 < 0\}$，集合 $N = \{x \mid x > 1\}$，求 $M \cup N$。
**【规范解答】**：
先解一元二次不等式：$x^2-x-6 < 0 \Rightarrow (x-3)(x+2) < 0 \Rightarrow -2 < x < 3$。
所以 $M = (-2, 3)$。又 $N = (1, +\infty)$。
画数轴取并集（合并全部区域），得 $M \cup N = (-2, +\infty)$。

**【考查知识点】**：Venn 图的识别与阴影部分的集合表示
**【变式 2-2（综合提升）】**
如图所示，全集为 $U$，集合 $A, B, C$ 为其子集，请写出阴影部分表示的集合。

![Venn图示意](./images/venn_2_2.png)

**【规范解答】**：
观察图形可知：阴影部分首先必须在 $A$ 和 $B$ 的重合区域内，即属于 $A \cap B$。
同时，它又被挖去了 $C$ 的部分，也就是说它不能在 $C$ 内，即属于 $C$ 的补集 $\complement_{U}C$。
因此，阴影部分表示的集合为：$(A \cap B) \cap (\complement_{U}C)$。

### 题型三：含参集合的关系（致命的空集陷阱）

**【考查知识点】**：集合包含关系、含参不等式、空集讨论
**【典例 3】** 已知集合 $A = \{x \mid -2 \leq x \leq 4\}$，集合 $B = \{x \mid m-1 \leq x \leq 2m\}$。若 $B \subseteq A$，求实数 $m$ 的取值范围。

**【思路点拨】**：一看到 $B \subseteq A$ 且 $B$ 里面带了未知数，**第一反应必须是：$B$ 会不会是空集？** 把空集情况讨论完，再去画数轴比较端点。

**【规范解答】**：
① 当 $m-1 > 2m$ 时，即 $m < -1$ 时，左端点比右端点还大，这种区间不存在，所以集合 $B$ 是空集 $\varnothing$。空集是任何集合的子集，显然 $B \subseteq A$ 成立，符合题意。
② 当 $m-1 \leq 2m$ 时，即 $m \geq -1$ 时，集合 $B$ 不是空集。
要使 $B \subseteq A$，根据数轴，$B$ 必须完全落在 $[-2, 4]$ 里面：
$$
\begin{cases}
m-1 \geq -2 \\
2m \leq 4
\end{cases}
$$
解得 $m \geq -1$ 且 $m \leq 2$。结合大前提 $m \geq -1$，得出 $-1 \leq m \leq 2$。
最后，把 ① 和 ② 的结果合并起来（取并集）：$m < -1$ 或 $-1 \leq m \leq 2$。
综上所述，实数 $m$ 的取值范围是 $m \leq 2$，即 $(-\infty, 2]$。

**【考查知识点】**：交集运算逆用、空集陷阱
**【变式 3-1（易错挖坑）】**
已知集合 $A = \{x \mid 1 < x < 3\}$，集合 $B = \{x \mid x > a\}$，若 $A \cap B = \varnothing$，求 $a$ 的取值范围。
**【规范解答】**：
$A \cap B = \varnothing$ 说明 $A$ 和 $B$ 在数轴上没有任何交集。
因为 $A = (1, 3)$，$B = (a, +\infty)$，要让它们碰不到面，$B$ 的起点 $a$ 必须在 $A$ 的终点 $3$ 的右边或者恰好等于 $3$。
（如果 $a=3$，此时 $B=(3, +\infty)$，不包含 $3$，而 $A$ 也不包含 $3$，两者交集仍然是空集！）
所以 $a \geq 3$。

**【考查知识点】**：一元二次方程判别式结合集合运算
**【变式 3-2（综合拔高）】**
已知集合 $A = \{x \mid x^2-3x+2=0\}$，集合 $B = \{x \mid x^2+mx+2=0\}$，若 $A \cup B = A$，求实数 $m$ 的值或取值范围。
**【规范解答】**：
先解出 $A = \{1, 2\}$。由 $A \cup B = A$ 可知，必然有 $B \subseteq A$。
同样，遇到 $B \subseteq A$ 第一步想什么？**判别式 $\Delta$！**
① 当 $\Delta = m^2-8 < 0$，即 $-2\sqrt{2} < m < 2\sqrt{2}$ 时，$B = \varnothing$，满足 $B \subseteq A$。
② 当 $\Delta = 0$ 时，$B$ 只有一个元素。要使 $B \subseteq A$，则 $B=\{1\}$ 或 $B=\{2\}$。
若 $B=\{1\}$，把 $x=1$ 代入方程得 $1+m+2=0 \Rightarrow m=-3$。检验发现当 $m=-3$ 时原方程为 $x^2-3x+2=0$，其实有两个根，矛盾！
同理 $B=\{2\}$ 时也矛盾（因为 $\Delta=0$ 要求两个根相等，但此方程不可能既 $\Delta=0$ 又有一根为 $1$ 或 $2$）。
③ 当 $\Delta > 0$ 时，$B$ 有两个不同元素。要使 $B \subseteq A$，只能是 $B = \{1, 2\}$。
此时原方程的两个根就是 $1$ 和 $2$，由韦达定理可知 $1+2 = -m \Rightarrow m=-3$。
综上，实数 $m$ 的取值范围是 $-2\sqrt{2} < m < 2\sqrt{2}$ 或 $m=-3$。

## 四、 当堂过关检测（限时 15 分钟）

**【教师引导话术】**：刚刚我们把易错点和所有题型都过了一遍，现在进入实战演练时间！给大家 15 分钟时间完成以下 5 道题，做完我们马上对答案！

**1. （基础选择）** 满足条件 $\{1, 2\} \subseteq M \subsetneq \{1, 2, 3, 4, 5\}$ 的集合 $M$ 的个数是（　　）
A. $7$　　B. $8$　　C. $15$　　D. $16$
**【解析】**：集合 $M$ 必须包含 $1, 2$ 两个元素，并且剩下的元素只能从 $\{3, 4, 5\}$ 里面挑。从这 $3$ 个元素里挑子集，共有 $2^3 = 8$ 种挑法。但是题目要求 $M$ 不能等于 $\{1, 2, 3, 4, 5\}$（因为是真子集 $\subsetneq$），所以要减去全挑的那一种情况，即 $8 - 1 = 7$。答案选 A。

**2. （基础选择）** 已知集合 $A = \{0, 1, 2\}$，$B = \{y \mid y = 2x, x \in A\}$，则 $A \cup B = $（　　）
A. $\{0\}$　　B. $\{0, 1, 2\}$　　C. $\{0, 1, 2, 4\}$　　D. $\{0, 2, 4\}$
**【解析】**：先求出 $B$。把 $x=0, 1, 2$ 分别代入 $y=2x$，得到 $y$ 的值为 $0, 2, 4$，所以 $B=\{0, 2, 4\}$。两者的并集就是全部合并并去重，得到 $\{0, 1, 2, 4\}$。选 C。

**3. （易错填空）** 设集合 $A=\{x \mid x^2-x=0\}$，集合 $B=\{x \mid ax=1\}$，若 $A \cap B = B$，则实数 $a$ 的取值集合为 ________。
**【解析】**：解得 $A=\{0, 1\}$。由 $A \cap B = B$ 知 $B \subseteq A$。注意讨论 $a=0$：当 $a=0$ 时，方程 $0 \cdot x = 1$ 无解，$B=\varnothing$，满足条件！当 $a \neq 0$ 时，$B=\{\frac{1}{a}\}$，由 $\frac{1}{a} \in A$，只能是 $\frac{1}{a} = 1 \Rightarrow a=1$（$\frac{1}{a}$ 不可能等于 $0$）。所以 $a$ 的值可以是 $0$ 或 $1$。填 $\{0, 1\}$。

**4. （计算拔高）** 已知全集 $U=\mathbb{R}$，集合 $A=\{x \mid -4 \leq x < 2\}$，集合 $B=\{x \mid -1 < x \leq 3\}$。
(1) 求 $A \cap (\complement_{U}B)$；
(2) 若集合 $C=\{x \mid x \leq a\}$，且 $A \cup B \subseteq C$，求 $a$ 的取值范围。
**【解析】**：
(1) $\complement_{U}B = (-\infty, -1] \cup (3, +\infty)$。画数轴求它与 $A$ 的交集，得 $A \cap (\complement_{U}B) = [-4, -1]$。
(2) $A \cup B = [-4, 3]$。因为 $A \cup B \subseteq C$，所以 $C$ 这个向左无限延伸的区间必须把 $[-4, 3]$ 完全盖住。画数轴可知，$C$ 的右端点 $a$ 必须在 $3$ 的右边或者重合，所以 $a \geq 3$。

## 五、 易错坑点防雷

- 🧨 **易错点 1（忘了空集）**：看到 $B \subseteq A$ 或是 $A \cup B = A$，脑海里第一反应必须蹦出“**$B$ 有没有可能是空集**”！如果不讨论空集，绝对会痛失 5 分。
  - **正确做法**：先令方程无解或区间不成立，把参数解出来。

- 🧨 **易错点 2（忘了检验互异性）**：求出未知数后，沾沾自喜直接写答案。
  - **正确做法**：强迫自己把解出来的数代回原集合，如果有像 $\{1, 1\}$ 这样长得一模一样的元素，马上把这个解划掉。

- 🧨 **易错点 3（补集的端点开闭搞反）**：求补集时，对着 $\leq$ 照样写 $\leq$。
  - **正确做法**：原集合包含的数（实心），补集绝对不包含（空心）。$\leq$ 的补集是 $>$， $<$ 的补集是 $\geq$。
