# 1.1 集合（高一基础巩固版）

---

## 一、 知识精讲与深度剖析

### 考点 1：集合及其关系

**1. 集合的含义与表示**
- **元素的三特性**：**确定性**、**互异性**、**无序性**。
  - *点拨：做题求出未知数后，一定要代回原集合，看有没有出现重复的元素（互异性检验）！*
- **元素与集合的关系**：属于（ $\in$ ）或不属于（ $\notin$ ）。
- **常用数集**：
  - 自然数集 $\mathbb{N}$ （包含 $0$）
  - 正整数集 $\mathbb{N}^*$
  - 整数集 $\mathbb{Z}$
  - 实数集 $\mathbb{R}$
- **集合的表示方法**：列举法、描述法、Venn 图。

**2. 集合间的基本关系**

| 关系 | 文字语言 | 记法 |
|:---:|:---|:---:|
| **相等** | 集合 $A$ 与集合 $B$ 的元素完全一样 | $A = B$ |
| **子集** | 集合 $A$ 中任意一个元素都在集合 $B$ 中（$A$ 小 $B$ 大） | $A \subseteq B$ |
| **真子集** | $A$ 是 $B$ 的子集，且 $B$ 中至少有一个元素不在 $A$ 中 | $A \subsetneq B$ |

> 💡 **子集个数公式（必背）**：
> 若集合 $A$ 有 $n$ 个元素：
> - 子集个数为 $2^n$
> - 真子集个数为 $2^n - 1$
> - 非空真子集个数为 $2^n - 2$

## 二、 必背符号与性质

已知全集 $U$，集合 $A$，$B$：

| 运算 | **并集** | **交集** | **补集** |
|:---:|:---:|:---:|:---:|
| **符号语言** | $A \cup B = \{ x \mid x \in A \text{ 或 } x \in B \}$ | $A \cap B = \{ x \mid x \in A \text{，且 } x \in B \}$ | $\complement_{U}{A} = \{ x \mid x \in U \text{，且 } x \notin A \}$ |
| **核心性质** | $A \cup A = A$ <br> $A \cup B = B \Leftrightarrow A \subseteq B$ | $A \cap A = A$ <br> $A \cap B = A \Leftrightarrow A \subseteq B$ | $A \cup (\complement_{U}{A}) = U$ <br> $A \cap (\complement_{U}{A}) = \varnothing$ |

**🔭 知识点拨（画图法则是王道）**
- **离散的数字集合**：找交集、并集时直接“找相同”或“全合并”。
- **连续的区间集合**（如 $x > 1$）：**必须画数轴**！画数轴时注意“实心点”代表包含等于号，“空心圈”代表不包含等于号。

## 三、 核心考向与基础题型巩固

### 题型一：集合的含义与表示（互异性检验）

**【考查知识点】**：集合元素的互异性、解简单方程
**【典例 1】** 已知集合 $A = \{1, x, x^2-x\}$，若 $0 \in A$，求实数 $x$ 的值。

**【思路点拨】**：集合里有三个元素，既然 $0$ 在集合里，那肯定是 $x$ 或者 $x^2-x$ 等于 $0$。解出来之后一定要记得验证！

**【规范解答】**：
因为 $0 \in A$，分两种情况讨论：
① 若 $x = 0$，则 $x^2-x = 0$。此时集合 $A = \{1, 0, 0\}$。
发现有两个 $0$，违背了元素的“互异性”，所以 $x=0$ 必须舍去。
② 若 $x^2-x = 0$，解得 $x = 0$ 或 $x = 1$。
当 $x = 0$ 时，违背互异性，舍去；
当 $x = 1$ 时，集合 $A = \{1, 1, 0\}$，同样违背互异性，舍去。
*(注：如果解出来都不行，说明题目条件不可能成立，但本题演示了完整的检验过程)*
等等，这里若都不成立，说明此题设条件下 $x$ 无解。
（正确命题示范：若 $x^2-x = 2$，此时 $x=2$ 或 $-1$ 代入验证即可）。
综上，此题中不存在满足条件的实数 $x$。

**【考查知识点】**：点集与数集的辨析
**【变式训练 1-1】**
集合 $M = \{y \mid y = x^2+1\}$ 与集合 $N = \{(x, y) \mid y = x^2+1\}$ 是一样的吗？为什么？

**【规范解答】**：
不一样。
集合 $M$ 前面的代表元素是 $y$，表示的是函数 $y = x^2+1$ 的**值域**，这是一个**数集**，结果是 $[1, +\infty)$。
集合 $N$ 前面的代表元素是 $(x,y)$，表示的是抛物线 $y = x^2+1$ 上的所有点，这是一个**点集**。
两者元素类型完全不同。

### 题型二：集合的基本运算（数轴与Venn图）

**【考查知识点】**：连续区间集合的交、并、补运算（必须画数轴）
**【典例 2】** 已知全集 $U = \mathbb{R}$，集合 $A = \{x \mid -1 \leq x < 3\}$，集合 $B = \{x \mid 2 < x \leq 5\}$。
求：(1) $A \cap B$；(2) $A \cup B$；(3) $\complement_{U}{A}$。

**【思路点拨】**：在草稿纸上画一条数轴，把 $-1, 3, 2, 5$ 四个点标出来，注意 $\leq$ 画实心， $<$ 画空心圈。

**【规范解答】**：
借助数轴：
(1) 交集是找两者的公共部分：$A \cap B = \{x \mid 2 < x < 3\}$，也可以写成区间 $(2, 3)$。
(2) 并集是把两者的范围合起来：$A \cup B = \{x \mid -1 \leq x \leq 5\}$，即 $[-1, 5]$。
(3) 补集是找 $U$ 中不属于 $A$ 的部分，注意端点反转（$A$ 中有 $-1$，补集中就没有；$A$ 中没有 $3$，补集中就有）：
$\complement_{U}{A} = \{x \mid x < -1 \text{ 或 } x \geq 3\}$，即 $(-\infty, -1) \cup [3, +\infty)$。

**【考查知识点】**：Venn 图的识别与阴影部分的集合表示
**【变式训练 2-1】**
如图所示，全集为 $U$，集合 $A, B, C$ 为其子集，请写出阴影部分表示的集合。

![Venn图示意](./images/venn_2_2.png)

**【规范解答】**：
观察图形可知：阴影部分首先必须在 $A$ 和 $B$ 的重合区域内，即属于 $A \cap B$。
同时，它又被挖去了 $C$ 的部分，也就是说它不能在 $C$ 内，即属于 $C$ 的补集 $\complement_{U}C$。
因此，阴影部分表示的集合为：$(A \cap B) \cap (\complement_{U}C)$。

### 题型三：含参集合的简单运算（空集陷阱）

**【考查知识点】**：集合包含关系与数轴端点比较
**【典例 3】** 已知集合 $A = \{x \mid -2 \leq x \leq 4\}$，集合 $B = \{x \mid m-1 \leq x \leq 2m\}$。若 $B \subseteq A$，求实数 $m$ 的取值范围。

**【思路点拨】**：$B$ 是 $A$ 的子集，说明 $B$ 的线段必须完全落在 $A$ 的线段里面。列不等式组即可。但一定要当心 $B$ 可能是空集！

**【规范解答】**：
因为区间 $B$ 含有参数 $m$，首先讨论 $B$ 是否为空集：
① 当 $m-1 > 2m$ 时，即 $m < -1$ 时，集合 $B$ 是空集 $\varnothing$。空集是任何集合的子集，符合题意。
② 当 $m-1 \leq 2m$ 时，即 $m \geq -1$ 时，集合 $B$ 不是空集。
要使 $B \subseteq A$，根据数轴，$B$ 的左端点不能比 $-2$ 小，$B$ 的右端点不能比 $4$ 大。列出不等式组：
$$
\begin{cases}
m-1 \geq -2 \\
2m \leq 4
\end{cases}
$$
解得 $m \geq -1$ 且 $m \leq 2$，即 $-1 \leq m \leq 2$。结合前提 $m \geq -1$，得出 $-1 \leq m \leq 2$。
综合 ① 和 ②，实数 $m$ 的取值范围是 $m \leq 2$，即 $(-\infty, 2]$。

## 四、 易错坑点防雷

- 🧨 **易错点 1（忘了空集）**：在做 $A \subseteq B$ 或 $A \cap B = A$ 这类题目时，如果 $A$ 是一个带参数的集合，**千万不要忘了讨论 $A = \varnothing$ 的情况！** 这是每次考试必考的送命点。

- 🧨 **易错点 2（忘了检验互异性）**：解出参数 $a$ 或 $x$ 的值之后，**必须**把它代回到原集合里看一眼，如果出现了类似 $\{1, 1\}$ 这样重复的数字，这个解必须立刻划掉！

- 🧨 **易错点 3（数轴端点空实心搞错）**：求补集的时候，如果原来的集合是 $\leq$（实心），那它的补集对应的地方就是 $<$（空心）。两者一定是反过来的，绝不能同时带有等于号。
