## 一、 知识精讲与深度剖析

### 考点 1：集合及其关系

**1. 集合的含义与表示**
- **元素的三特性**：**确定性**、**互异性**、**无序性**。
  - *点拨：互异性是含参集合问题中最容易遗漏的检验步骤。*
- **元素与集合的关系**：属于（用符号 $\in$ 表示）或不属于（用符号 $\notin$ 表示）。
- **常用数集及符号**：
  - 非负整数集（自然数集）$\mathbb{N}$
  - 正整数集 $\mathbb{N}^*$ （或 $\mathbb{N}_+$）
  - 整数集 $\mathbb{Z}$
  - 有理数集 $\mathbb{Q}$
  - 实数集 $\mathbb{R}$
- **集合的表示方法**：列举法、描述法、图示法（Venn 图）。

**2. 集合间的基本关系**

| 关系 | 文字语言 | 记法 |
|:---:|:---|:---:|
| **相等** | 集合 $A$ 的任何一个元素都是集合 $B$ 的元素，同时 $B$ 的任何一个元素也都是 $A$ 的元素 | $A = B$ |
| **子集** | 集合 $A$ 中任意一个元素均为集合 $B$ 中的元素 | $A \subseteq B$ 或 $B \supseteq A$ |
| **真子集** | 如果 $A \subseteq B$，但存在元素 $x \in B$，且 $x \notin A$，则称 $A$ 是 $B$ 的真子集 | $A \subsetneq B$ 或 $B \supsetneq A$ |

> 💡 **有限集的子集个数推导**：
> 设集合 $A$ 是有 $n$ 个元素的有限集，即 $\text{card}(A) = n$（$n \in \mathbb{N}^*$）。对于集合中的每一个元素，都有"选"或"不选" $2$ 种状态，根据乘法原理，总组合数为 $2 \times 2 \times \dots \times 2 = 2^n$。
> - 子集个数为 $2^n$
> - 真子集个数为 $2^n - 1$
> - 非空真子集个数为 $2^n - 2$

## 二、 必背符号与性质

已知全集 $U$，集合 $A$，$B$：

| 运算 | **并集** | **交集** | **补集** |
|:---:|:---:|:---:|:---:|
| **符号语言** | $A \cup B = \{ x \mid x \in A \text{ 或 } x \in B \}$ | $A \cap B = \{ x \mid x \in A \text{，且 } x \in B \}$ | $\complement_{U}{A} = \{ x \mid x \in U \text{，且 } x \notin A \}$ |
| **核心性质** | $A \cup A = A$ <br> $A \cup B = B \cup A$ <br> $A \cup B = B \Leftrightarrow A \subseteq B$ | $A \cap A = A$ <br> $A \cap B = B \cap A$ <br> $A \cap B = A \Leftrightarrow A \subseteq B$ | $A \cup (\complement_{U}{A}) = U$ <br> $A \cap (\complement_{U}{A}) = \varnothing$ <br> $\complement_{U}{(\complement_{U}{A})} = A$ |

**🔭 知识拓展（中培拔高必备）**

**1. 德·摩根定律（反演律）**：
- $\complement_{U}{(A \cup B)} = (\complement_{U}{A}) \cap (\complement_{U}{B})$
- $\complement_{U}{(A \cap B)} = (\complement_{U}{A}) \cup (\complement_{U}{B})$

**2. 容斥原理**：
- $\text{card}(A \cup B) = \text{card}(A) + \text{card}(B) - \text{card}(A \cap B)$

### 题型一：集合的含义与表示

**【考查知识点】**：集合元素的互异性检验、解一元二次方程
**【典例 1】** 已知集合 $A = \{a, a^2+a, 1\}$，若 $2 \in A$，求实数 $a$ 的值。

**【思路点拨】**：解含参集合问题，先假设某个元素等于 $2$，解出 $a$ 后，**必须**将 $a$ 代回原集合，检验是否违背了元素的“互异性”原则。

**【规范解答】**：
因为 $2 \in A$，所以可能有两种情况：
① 若 $a = 2$，则 $a^2+a = 4+2=6$。此时 $A = \{2, 6, 1\}$，满足互异性，故 $a=2$ 符合题意。
② 若 $a^2+a = 2$，解得 $a=1$ 或 $a=-2$。
当 $a=1$ 时，$A=\{1, 2, 1\}$，违背互异性，舍去；
当 $a=-2$ 时，$A=\{-2, 2, 1\}$，满足互异性，符合题意。
综上所述，$a$ 的值为 $2$ 或 $-2$。

**【考查知识点】**：集合的概念、点集与数集的辨析
**【变式训练 1-1】**
给出下列集合：
① $A=\{x \mid x^2-3x+2=0\}$；② $B=\{y \mid y=x^2-3x+2\}$；③ $C=\{(x, y) \mid y=x^2-3x+2\}$。
判断它们是否为同一集合，并说明理由。

**【规范解答】**：
它们不是同一集合。
集合 $A$ 的元素是使得一元二次方程成立的 $x$ 的值，是数集，解得 $A=\{1, 2\}$；
集合 $B$ 的元素是二次函数 $y=x^2-3x+2$ 的函数值，是数集，化简得 $y=(x-\frac{3}{2})^2-\frac{1}{4}$，故 $B=[-\frac{1}{4}, +\infty)$；
集合 $C$ 的元素是二次函数图象上的点，是点集。
综上，三者代表的元素属性完全不同，故不是同一集合。

### 题型二：集合的基本运算（Venn图与交并补）

**【考查知识点】**：解一元二次不等式、离散集与连续集的交集运算
**【典例 2】**（2023·新高考Ⅰ卷）已知集合 $M = \{-2, -1, 0, 1, 2\}$，$N = \{x \mid x^2-x-6 \geq 0\}$，则 $M \cap N = $（　）
A. $\{-2, -1, 0, 1\}$　　B. $\{0, 1, 2\}$　　C. $\{-2\}$　　D. $\{2\}$

**【思路点拨】**：先解出集合 $N$ 的范围，然后再去筛选离散集合 $M$ 中符合条件的元素。切忌将离散集合误认为连续区间。

**【规范解答】**：答案选 **C**。
$N: x^2-x-6 \geq 0 \Rightarrow (x-3)(x+2) \geq 0$，解得 $x \leq -2$ 或 $x \geq 3$。
即 $N = (-\infty, -2] \cup [3, +\infty)$。
因为 $M = \{-2, -1, 0, 1, 2\}$，所以 $M \cap N = \{-2\}$。

**【考查知识点】**：对数函数定义域、指数不等式解法、补集与并集的综合运算
**【变式训练 2-1】（选自《教材帮》）**
已知全集 $U = \mathbb{R}$，集合 $A=\{x \mid \log_2(x-1) < 1\}$，集合 $B=\{x \mid 2^x \geq 4\}$，求 $A \cup (\complement_{U}B)$。

**【规范解答】**：
求 $A$：由 $\log_2(x-1) < \log_2 2$ 且 $x-1 > 0$，得 $1 < x < 3$，即 $A=(1, 3)$。
求 $B$：由 $2^x \geq 2^2$ 得 $x \geq 2$，即 $B=[2, +\infty)$。
求 $\complement_{U}B$：因为 $U = \mathbb{R}$，所以 $\complement_{U}B = (-\infty, 2)$。
求 $A \cup (\complement_{U}B)$：$(1, 3) \cup (-\infty, 2) = (-\infty, 3)$。

**【考查知识点】**：集合交集、补集的基本运算（离散型）
**【变式训练 2-2】（选自《必刷题》）**
已知全集 $U = \{1, 2, 3, 4, 5, 6, 7\}$，集合 $A = \{1, 2, 3, 4\}$，集合 $B = \{3, 4, 5, 6\}$，集合 $C = \{4, 6, 7\}$。
求：$(A \cap B) \cap (\complement_{U}C)$。

**【规范解答】**：
首先求 $A \cap B$：因为 $A = \{1, 2, 3, 4\}$，$B = \{3, 4, 5, 6\}$，所以 $A \cap B = \{3, 4\}$。
接着求 $\complement_{U}C$：因为 $U = \{1, 2, 3, 4, 5, 6, 7\}$，$C = \{4, 6, 7\}$，所以 $\complement_{U}C = \{1, 2, 3, 5\}$。
最后求交集：$(A \cap B) \cap (\complement_{U}C) = \{3, 4\} \cap \{1, 2, 3, 5\} = \{3\}$。

### 题型三：含参集合的关系与运算（分类讨论与空集陷阱）

**【考查知识点】**：集合并集的定义、连续区间的端点值讨论
**【典例 3】** 已知集合 $A = \{x \mid (x-2)(x-3) \geq 0\}$，集合 $B = \{x \mid x > a-1\}$。若 $A \cup B = \mathbb{R}$，则实数 $a$ 的取值范围是（　　）
A. $(3,+\infty)$　　B. $[2,+\infty)$　　C. $(-\infty,2]$　　D. $(-\infty,3]$

**【思路点拨】**：先解出集合 $A$ 的补集。因为并集是全体实数，所以集合 $B$ 必须完全覆盖住 $A$ 的"缺口"（即 $A$ 的补集区域），借多数轴直观判断端点取舍。

**【规范解答】**：答案选 **D**。
$$A = (-\infty, 2] \cup [3, +\infty)$$
$A$ 的补集为开区间 $(2,3)$，即这是 $A$ 覆盖不到的区域。
要使 $A \cup B = \mathbb{R}$，集合 $B = (a-1, +\infty)$ 必须覆盖 $(2,3)$ 中所有的点，甚至包括左端点 $2$。
借助数轴可知，必须满足：$a - 1 \leq 2 \Rightarrow a \leq 3$
故 $a$ 的取值范围为 $(-\infty, 3]$。

**【考查知识点】**：集合的包含关系、空集 $\varnothing$ 的分类讨论陷阱
**【变式训练 3-1】（选自《五三》）**
若集合 $A=\{x \mid -2 \leq x \leq 5\}$，集合 $B=\{x \mid m+1 \leq x \leq 2m-1\}$，若 $B \subseteq A$，求实数 $m$ 的取值范围。

**【规范解答】**：
由于 $B$ 的区间端点均含参 $m$，必须首先讨论 $B$ 是否为空集！
① 当 $B = \varnothing$ 时，即 $m+1 > 2m-1 \Rightarrow m < 2$ 时，此时空集是任何集合的子集，必然有 $B \subseteq A$ 成立；
② 当 $B \neq \varnothing$ 时，即 $m \geq 2$ 时，若要 $B \subseteq A$，根据数轴必须满足：
$$
\begin{cases}
m+1 \geq -2 \\
2m-1 \leq 5
\end{cases}
$$
解得 $-3 \leq m \leq 3$。结合 $m \geq 2$，得 $2 \leq m \leq 3$。
综合 ① 和 ②，实数 $m$ 的取值范围是 $(-\infty, 3]$。

**【考查知识点】**：一元二次方程根的分布、韦达定理与集合元素的互异性综合
**【变式训练 3-2】（选自《教材帮》拔高题）**
已知集合 $A=\{1, 2\}$，集合 $B=\{x \mid x^2+ax+b=0\}$，若 $A \cup B = A$，求所有可能的实数对 $(a,b)$ 组成的集合。

**【规范解答】**：
由 $A \cup B = A$ 可知，集合 $B \subseteq A$。根据方程的解，分以下三种情况讨论：
① $B = \varnothing$：此时方程无解，判别式 $\Delta = a^2-4b < 0$ 即可。这种情况下的实数对有无数个。
② $B$ 为单元素集（即方程有两个相等实根）：此时 $\Delta = a^2-4b = 0$。
由于 $B \subseteq A$，所以 $B=\{1\}$ 或 $B=\{2\}$。
若 $B=\{1\}$，则原方程为 $(x-1)^2=0$，展开得 $x^2-2x+1=0$，所以 $a=-2, b=1$；
若 $B=\{2\}$，则原方程为 $(x-2)^2=0$，展开得 $x^2-4x+4=0$，所以 $a=-4, b=4$。
③ $B$ 为双元素集（即方程有两个不相等实根）：此时 $\Delta > 0$。
由于 $B \subseteq A$ 且 $B$ 有两个不同元素，故必然有 $B=\{1, 2\}$。
根据韦达定理，两根之和 $1+2=-a \Rightarrow a=-3$，两根之积 $1 \times 2=b \Rightarrow b=2$。
综上所述，若不考虑 $\Delta<0$ 的无限情况，仅当方程有解时，实数对 $(a,b)$ 可以为 $(-2,1), (-4,4), (-3,2)$。

## 四、 易错坑点防雷

- 🧨 **易错点 1（空集必须讨论）**：在解决 $B \subseteq A$ 等集合包含关系问题时，含有参数的集合 $B$ 有可能为空集 $\varnothing$。**空集是任何集合的子集，极易漏解！**

- 🧨 **易错点 2（元素互异性的检验）**：在含有参数的集合（如 $A = \{a, a^2, 1\}$）中求参数值时，解出参数后必须代回原集合，检验集合中是否出现了重复元素。若出现重复，该解必须舍去。

- 🧨 **易错点 3（点集与数集的混淆）**：
  集合 $M_1 = \{y \mid y = x^2+1, x \in \mathbb{R}\}$ 是**数集**（函数的值域，$[1, +\infty)$）；
  集合 $M_2 = \{(x,y) \mid y = x^2+1, x \in \mathbb{R}\}$ 是**点集**（抛物线上的点）。两者本质完全不同，不可混淆。

- 🧨 **易错点 4（补集端点取舍）**：利用数轴求补集时，原集合的开/闭端点对应补集的闭/开端点，务必仔细判断 $<$ 与 $\leq$ 的边界。
