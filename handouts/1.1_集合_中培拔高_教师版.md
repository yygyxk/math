# 1.1 集合（中培拔高版）

## 一、 知识精讲与深度剖析

### 考点 1：集合及其关系

**1. 集合的含义与表示**
- **元素的三特性**：**确定性**、**互异性**、**无序性**。
  - *点拨：互异性是含参集合问题中最容易遗漏的检验步骤。*
- **元素与集合的关系**：属于（用符号 $\in$ 表示）或不属于（用符号 $\notin$ 表示）。
- **常用数集及符号**：
  - 非负整数集（自然数集）$\mathbb{N}$
  - 正整数集 $\mathbb{N}^*$ （或 $\mathbb{N}_+$）
  - 整数集 $\mathbb{Z}$
  - 有理数集 $\mathbb{Q}$
  - 实数集 $\mathbb{R}$
- **集合的表示方法**：列举法、描述法、图示法（Venn 图）。

**2. 集合间的基本关系**

| 关系 | 文字语言 | 记法 |
|:---:|:---|:---:|
| **相等** | 集合 $A$ 的任何一个元素都是集合 $B$ 的元素，同时 $B$ 的任何一个元素也都是 $A$ 的元素 | $A = B$ |
| **子集** | 集合 $A$ 中任意一个元素均为集合 $B$ 中的元素 | $A \subseteq B$ 或 $B \supseteq A$ |
| **真子集** | 如果 $A \subseteq B$，但存在元素 $x \in B$，且 $x \notin A$，则称 $A$ 是 $B$ 的真子集 | $A \subsetneq B$ 或 $B \supsetneq A$ |

> 💡 **有限集的子集个数推导**：
> 设集合 $A$ 是有 $n$ 个元素的有限集，即 $\text{card}(A) = n$（$n \in \mathbb{N}^*$）。对于集合中的每一个元素，都有"选"或"不选" $2$ 种状态，根据乘法原理，总组合数为 $2 \times 2 \times \dots \times 2 = 2^n$。
> - 子集个数为 $2^n$
> - 真子集个数为 $2^n - 1$
> - 非空真子集个数为 $2^n - 2$

## 二、 必背符号与性质

已知全集 $U$，集合 $A$，$B$：

| 运算 | **并集** | **交集** | **补集** |
|:---:|:---:|:---:|:---:|
| **符号语言** | $A \cup B = \{ x \mid x \in A \text{ 或 } x \in B \}$ | $A \cap B = \{ x \mid x \in A \text{，且 } x \in B \}$ | $\complement_{U}{A} = \{ x \mid x \in U \text{，且 } x \notin A \}$ |
| **核心性质** | $A \cup A = A$ <br> $A \cup B = B \cup A$ <br> $A \cup B = B \Leftrightarrow A \subseteq B$ | $A \cap A = A$ <br> $A \cap B = B \cap A$ <br> $A \cap B = A \Leftrightarrow A \subseteq B$ | $A \cup (\complement_{U}{A}) = U$ <br> $A \cap (\complement_{U}{A}) = \varnothing$ <br> $\complement_{U}{(\complement_{U}{A})} = A$ |

**🔭 知识拓展（中培拔高必备）**

**1. 德·摩根定律（反演律）**：
- $\complement_{U}{(A \cup B)} = (\complement_{U}{A}) \cap (\complement_{U}{B})$
- $\complement_{U}{(A \cap B)} = (\complement_{U}{A}) \cup (\complement_{U}{B})$

**2. 容斥原理**：
- $\text{card}(A \cup B) = \text{card}(A) + \text{card}(B) - \text{card}(A \cap B)$

## 三、 核心题型与精选变式（限量版）

### 题型一：含参集合的关系与运算（分类讨论思想）

**【典例】** 已知集合 $A = \{x \mid (x-2)(x-3) \geq 0\}$，集合 $B = \{x \mid x > a-1\}$。若 $A \cup B = \mathbb{R}$，则实数 $a$ 的取值范围是（　　）

A. $(3,+\infty)$　　B. $[2,+\infty)$　　C. $(-\infty,2]$　　D. $(-\infty,3]$

**【思路点拨】**：
先解出集合 $A$ 的补集。因为并集是全体实数，所以集合 $B$ 必须完全覆盖住 $A$ 的"缺口"（即 $A$ 的补集区域），借多数轴直观判断端点取舍。

**【规范解答】**：
答案选 **D**。
$$A = (-\infty, 2] \cup [3, +\infty)$$
$A$ 的补集为开区间 $(2,3)$，即这是 $A$ 覆盖不到的区域。
要使 $A \cup B = \mathbb{R}$，集合 $B = (a-1, +\infty)$ 必须覆盖 $(2,3)$ 中所有的点，甚至包括左端点 $2$。
借助数轴可知，必须满足：
$$a - 1 \leq 2 \Rightarrow a \leq 3$$
故 $a$ 的取值范围为 $(-\infty, 3]$。

**【变式训练 1-1】（新高考拔高）**
已知集合 $A = \{x \mid x^2 - 3x + 2 = 0\}$，集合 $B = \{x \mid ax - 2 = 0\}$。若 $B \subseteq A$，求实数 $a$ 的所有可能取值组成的集合。

**【规范解答】**：
$$A = \{1, 2\}$$
因为 $B \subseteq A$，所以 $B$ 可能是 $\varnothing$、$ \{1\}$ 或 $\{2\}$。
① 当 $B = \varnothing$ 时，方程 $ax - 2 = 0$ 无解，此时 $a = 0$；
② 当 $B = \{1\}$ 时，将 $x = 1$ 代入方程，得 $a - 2 = 0 \Rightarrow a = 2$；
③ 当 $B = \{2\}$ 时，将 $x = 2$ 代入方程，得 $2a - 2 = 0 \Rightarrow a = 1$。
综上，实数 $a$ 的所有可能取值组成的集合为 $\{0, 1, 2\}$。

## 四、 易错坑点防雷

- 🧨 **易错点 1（空集必须讨论）**：在解决 $B \subseteq A$ 等集合包含关系问题时，含有参数的集合 $B$ 有可能为空集 $\varnothing$。**空集是任何集合的子集，极易漏解！**

- 🧨 **易错点 2（元素互异性的检验）**：在含有参数的集合（如 $A = \{a, a^2, 1\}$）中求参数值时，解出参数后必须代回原集合，检验集合中是否出现了重复元素。若出现重复，该解必须舍去。

- 🧨 **易错点 3（点集与数集的混淆）**：
  集合 $M_1 = \{y \mid y = x^2+1, x \in \mathbb{R}\}$ 是**数集**（函数的值域，$[1, +\infty)$）；
  集合 $M_2 = \{(x,y) \mid y = x^2+1, x \in \mathbb{R}\}$ 是**点集**（抛物线上的点）。两者本质完全不同，不可混淆。
