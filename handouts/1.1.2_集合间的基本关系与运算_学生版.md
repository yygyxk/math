## 一、 知识精讲与深度剖析（对标《教材帮》深度）

### 1. 集合间的基本关系
- **子集**：如果集合 $A$ 中任意一个元素都是集合 $B$ 的元素，则称 $A$ 是 $B$ 的子集，记作 $A \subseteq B$ 或 $B \supseteq A$。
  - **空集特权**：空集是任何集合的子集（$\emptyset \subseteq A$）。
  - **自身特权**：任何一个集合是它本身的子集（$A \subseteq A$）。
- **真子集**：如果 $A \subseteq B$，且 $A \neq B$（即集合 $B$ 中至少有一个元素不属于 $A$），则称 $A$ 是 $B$ 的________，记作 $A \subsetneqq B$。
  - **空集特权**：空集是任何**非空集合**的真子集。
- **集合相等**：如果 $A \subseteq B$ 且 $B \subseteq A$，则 $A = B$。

### 2. 【教材帮深度拓展】子集个数的计算公式（常考易错点！）
已知集合 $A$ 中含有 $n$ 个元素：
- 集合 $A$ 的**子集**个数为：________ 个。
- 集合 $A$ 的**真子集**个数为：________ 个（排除了自身）。
- 集合 $A$ 的**非空子集**个数为：________ 个（排除了空集）。
- 集合 $A$ 的**非空真子集**个数为：________ 个（排除了空集和自身）。

### 3. 集合的基本运算
- **交集**：$A \cap B = \{x \mid \underline{\quad\quad\quad\quad} \}$。（寻找公共部分）
- **并集**：$A \cup B = \{x \mid \underline{\quad\quad\quad\quad} \}$。（合并所有元素）
- **补集**：$\complement_U A = \{x \mid \underline{\quad\quad\quad\quad} \}$。（全集中剔除 $A$ 的部分）
- **【教材帮拓展】德·摩根定律（反演律）**：
  - $\complement_U (A \cap B) = \underline{\quad\quad\quad\quad}$
  - $\complement_U (A \cup B) = \underline{\quad\quad\quad\quad}$
  - 记忆口诀：“破括号，交变并，并变交”。
