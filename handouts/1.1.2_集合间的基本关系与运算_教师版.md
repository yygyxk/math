## 一、 知识精讲与深度剖析（对标《教材帮》深度）

### 1. 集合间的基本关系
- **子集**：如果集合 $A$ 中任意一个元素都是集合 $B$ 的元素，则称 $A$ 是 $B$ 的子集，记作 $A \subseteq B$ 或 $B \supseteq A$。
  - **空集特权**：空集是任何集合的子集（$\emptyset \subseteq A$）。
  - **自身特权**：任何一个集合是它本身的子集（$A \subseteq A$）。
- **真子集**：如果 $A \subseteq B$，且 $A \neq B$（即集合 $B$ 中至少有一个元素不属于 $A$），则称 $A$ 是 $B$ 的真子集，记作 $A \subsetneqq B$。
  - **空集特权**：空集是任何**非空集合**的真子集。
- **集合相等**：如果 $A \subseteq B$ 且 $B \subseteq A$，则 $A = B$。

### 2. 【教材帮深度拓展】子集个数的计算公式（常考易错点！）
已知集合 $A$ 中含有 $n$ 个元素：
- 集合 $A$ 的**子集**个数为：**$2^n$** 个。
- 集合 $A$ 的**真子集**个数为：**$2^n - 1$** 个（排除了自身）。
- 集合 $A$ 的**非空子集**个数为：**$2^n - 1$** 个（排除了空集）。
- 集合 $A$ 的**非空真子集**个数为：**$2^n - 2$** 个（排除了空集和自身）。

### 3. 集合的基本运算
- **交集**：$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$。（寻找公共部分）
- **并集**：$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$。（合并所有元素）
- **补集**：$\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$。（全集中剔除 $A$ 的部分）
- **【教材帮拓展】德·摩根定律（反演律）**：
  - $\complement_U (A \cap B) = (\complement_U A) \cup (\complement_U B)$
  - $\complement_U (A \cup B) = (\complement_U A) \cap (\complement_U B)$
  - 记忆口诀：“破括号，交变并，并变交”。

## 二、 必背符号与运算性质

| 运算性质 | 交集 ($A \cap B$) | 并集 ($A \cup B$) | 备注推论 |
|:---|:---|:---|:---|
| **空集/全集参与** | $A \cap \emptyset = \emptyset$ | $A \cup \emptyset = A$ | 交集变小，并集变大 |
| **自身参与** | $A \cap A = A$ | $A \cup A = A$ | 幂等律 |
| **吸收关系** | 若 $A \subseteq B$，则 $A \cap B = A$ | 若 $A \subseteq B$，则 $A \cup B = B$ | **(解含参问题的核心转化！)** |

## 四、 核心题型与精选变式（全面覆盖与难度递增版）

### 题型一：集合子集与真子集的判定（基础辨析）
**【典例1】**
判断下列关系是否正确：
① $\emptyset \subseteq \{0\}$； ② $0 \in \emptyset$； ③ $\{1, 2\} \subseteq \{1, 2, 3\}$； ④ $\{x \mid x^2 = 1\} = \{1, -1\}$。

- **【思路点拨】** 分清元素与集合的关系用 $\in$ 或 $\notin$，集合与集合的关系用 $\subseteq$ 或 $\subsetneqq$ 或 $=$。
- **【规范解答】**
  ① 正确。空集是任何集合的子集。
  ② 错误。空集中没有任何元素，$0 \notin \emptyset$。
  ③ 正确。$\{1, 2\}$ 中的元素都在 $\{1, 2, 3\}$ 中。
  ④ 正确。方程 $x^2=1$ 的解就是 $1, -1$。
  故正确的有 ①③④。

**【阶梯变式 1-1】**（基础）
集合 $A = \{1, 2\}$ 与集合 $B = \{ (1, 2) \}$ 的关系是（   ）
A. $A = B$    B. $A \subseteq B$    C. $B \subseteq A$    D. 没有任何包含关系
**【规范解答】** D。$A$ 的元素是数字1和2；$B$ 的元素是数对(1,2)，元素类型完全不同，互不包含。

### 题型二：子集个数的计算（公式直接应用，难度递增）
**【典例2】**
已知集合 $A = \{1, 2, 3, 4\}$，求：
(1) 集合 $A$ 的子集个数；
(2) 集合 $A$ 的非空真子集个数。

- **【思路点拨】** 直接套用教材帮拓展公式，识别 $n=4$。
- **【规范解答】**
  集合 $A$ 中含有 4 个元素。
  (1) 子集个数为 $2^4 = 16$ 个。
  (2) 非空真子集个数为 $2^4 - 2 = 16 - 2 = 14$ 个。

**【阶梯变式 2-1】**（中等综合）
满足条件 $\{1, 2\} \subseteq X \subsetneqq \{1, 2, 3, 4, 5\}$ 的集合 $X$ 共有多少个？
**【规范解答】** 集合 $X$ 必须包含 $1, 2$，所以变化的部分只能从 $\{3, 4, 5\}$ 中选取。由于是真子集，不能全选 $\{3, 4, 5\}$。所以共有 $2^3 - 1 = 7$ 个。

### 题型三：利用子集关系求参数（核心重难点：防雷空集）
**【典例3】**（高考极高频考法）
已知集合 $A = \{x \mid -2 \le x \le 5\}$，集合 $B = \{x \mid m+1 \le x \le 2m-1\}$。若 $B \subseteq A$，求实数 $m$ 的取值范围。

- **【思路点拨】** 只要见到 $B \subseteq A$，第一步**必须**强制分类讨论集合 $B$ 是否为空集！
- **【规范解答】**
  ① 当 $B = \emptyset$ 时，满足 $B \subseteq A$。此时需满足 $m+1 > 2m-1$，解得 $m < 2$。
  ② 当 $B \neq \emptyset$ 时，必须同时满足：
     $\begin{cases} m+1 \le 2m-1 \text{ (保证 B 不为空)} \\ m+1 \ge -2 \text{ (左端点不超出 A)} \\ 2m-1 \le 5 \text{ (右端点不超出 A)} \end{cases}$
     解不等式组得：$2 \le m \le 3$。
  综合 ① 和 ②，实数 $m$ 的取值范围是 $m < 2$ 或 $2 \le m \le 3$，即 $m \le 3$。

**【阶梯变式 3-1】**（中等难度强化）
已知 $A = \{x \mid -1 < x < 3\}$，$B = \{x \mid x < a\}$，若 $A \subseteq B$，则实数 $a$ 的取值范围是________。
**【规范解答】** 画数轴可知，要完全盖住 $A$，$a$ 必须在 3 的右侧或等于 3（由于 $A$ 在 3 处是开区间，所以 $a=3$ 时 $B=\{x \mid x<3\}$ 恰好包含了 $A$）。故 $a \ge 3$。

**【阶梯变式 3-2】**（压轴挑战，交集转化）
已知 $A = \{x \mid x^2 - 3x + 2 = 0\}$，$B = \{x \mid ax - 2 = 0\}$。若 $A \cap B = B$，求 $a$ 的值。
**【规范解答】** 由 $A \cap B = B$ 可等价转化为 $B \subseteq A$。
$A = \{1, 2\}$。
若 $B = \emptyset$，此时方程 $ax-2=0$ 无解，故 $a=0$。
若 $B \neq \emptyset$，则 $x = \frac{2}{a} \in \{1, 2\}$，解得 $a=2$ 或 $a=1$。
故 $a$ 的值为 $0, 1, 2$。（少写一个 $0$ 就是送掉 5 分！）

### 题型四：集合交并补综合运算（基础送分题）
**【典例4】**（2024·北京卷变形）
已知全集 $U = \mathbb{R}$，集合 $A = \{x \mid 0 \le x \le 3\}$，$B = \{x \mid x^2 - x - 2 > 0\}$，求 $A \cup B$ 和 $A \cap (\complement_U B)$。

- **【思路点拨】** 先解二次不等式化简 $B$，再画数轴！
- **【规范解答】**
  解 $x^2 - x - 2 > 0$，得 $x < -1$ 或 $x > 2$。
  所以 $B = \{x \mid x < -1 \text{ 或 } x > 2\}$。
  $\complement_U B = \{x \mid -1 \le x \le 2\}$。
  借助数轴：
  $A \cup B = \{x \mid x < -1 \text{ 或 } x \ge 0\}$。
  $A \cap (\complement_U B) = \{x \mid 0 \le x \le 2\}$。

## 五、 衡中模式·当堂过关检测（高压限时 10 分钟）
> **测验要求**：高压极限输出，题量设置临界于“刚刚好做不完”。请拿出秒表的紧迫感！

### 【A组·基础限时秒杀】（建议用时 3 分钟）
1. 集合 $\{0, 1, 2\}$ 的真子集个数是 ________。
   **【解答】** $2^3 - 1 = 7$。
2. （判断）若 $A \subseteq B$，则 $A \cap B = A$。 （   ）
   **【解答】** 正确。
3. 全集 $U=\{1,2,3,4,5\}$，$A=\{1,3,5\}$，$B=\{2,3,4\}$，则 $\complement_U (A \cup B) =$ ________。
   **【解答】** $A \cup B = \{1,2,3,4,5\}$，所以其补集为 $\emptyset$。

### 【B组·中等综合提升】（建议用时 4 分钟）
4. 已知集合 $A = \{x \mid x > 2\}$，$B = \{x \mid m-1 \le x \le 2m\}$。若 $B \subseteq A$，求 $m$ 的取值范围。
   **【解答】** 若 $B=\emptyset$，则 $m-1 > 2m \Rightarrow m < -1$。若 $B \neq \emptyset$，则需 $\begin{cases} m-1 \le 2m \\ m-1 > 2 \end{cases}$，解得 $m > 3$。综合得 $m < -1$ 或 $m > 3$。
5. 若 $A = \{x \mid x^2=1\}$，$B = \{x \mid x^2 - 2x + m = 0\}$，且 $A \cup B = A$，求实数 $m$ 的值。
   **【解答】** $A=\{-1, 1\}$。因为 $A \cup B = A$，所以 $B \subseteq A$。方程 $\Delta = 4 - 4m$。
   若 $\Delta < 0$ 即 $m > 1$，$B=\emptyset$，满足。
   若 $\Delta = 0$ 即 $m = 1$，$B=\{1\}$，满足。
   若 $\Delta > 0$ 即 $m < 1$，$B$ 有两个不同的实根。必须是 $1$ 和 $-1$。此时根据韦达定理，两根之和为 $2$，但 $1+(-1)=0 \neq 2$，矛盾。
   故 $m \ge 1$。

### 【C组·拔高压轴挑战】（建议用时 3 分钟）
6. 满足 $A \cup B = \{1, 2, 3\}$ 的有序集合对 $(A, B)$ 共有多少对？
   **【解答】** 对于元素 $1$，它必须在 $A$ 中或 $B$ 中，有 3 种情况（在 $A$ 不在 $B$、在 $B$ 不在 $A$、在 $A$ 且在 $B$）。元素 $2$ 和 $3$ 同理。故共有 $3^3 = 27$ 对。

## 六、 易错坑点防雷

- 🧨 **易错点1**：集合子集与真子集的公式记混。
  **正确做法**：子集是 $2^n$，真子集是去掉了自己所以是 $2^n-1$，非空真子集去掉了自己和空集所以是 $2^n-2$。
- 🧨 **易错点2**：处理 $B \subseteq A$ 时，直接列出包含的不等式组，导致丢分解。
  **正确做法**：凡遇到 $B \subseteq A$ 或者 $A \cap B = B$ 或者 $A \cup B = A$，必须下意识写出第一行：**分类讨论 $B = \emptyset$**。
